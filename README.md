# NEXO STORE — Flask

متجر عربي RTL مبني على واجهة HTML الأصلية مع خادم Python/Flask وقاعدة بيانات SQLite للطلبات.

## التشغيل على Windows
1. ثبّت Python 3.11 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. أنشئ بيئة افتراضية: `py -m venv .venv`
4. فعّلها: `.venv\Scripts\activate`
5. ثبّت المتطلبات: `pip install -r requirements.txt`
6. انسخ `.env.example` إلى `.env` وعدّل الإعدادات. يُقرأ ملف `.env` تلقائياً عند تثبيت المتطلبات.
7. شغّل: `python app.py`
8. افتح `http://127.0.0.1:5000`.

## لوحة إدارة الطلبات
1. انسخ `.env.example` إلى `.env`.
2. غيّر قيمة `ADMIN_PASSWORD` إلى كلمة مرور قوية وفريدة، وغيّر `SECRET_KEY` إلى قيمة عشوائية طويلة.
3. شغّل المتجر ثم افتح `http://127.0.0.1:5000/admin/login`.
4. سجّل الدخول بكلمة المرور التي وضعتها في `ADMIN_PASSWORD`.
5. تعرض اللوحة الطلبات وتفاصيل العميل والمنتجات، وتتيح تغيير الحالة إلى: جديد، قيد التجهيز، تم الشحن، تم التسليم، أو ملغي. كما تعرض إجمالي المبيعات المحتسبة وتحدّث نفسها كل 10 ثوانٍ.
6. اضغط «تفعيل تنبيهات المتصفح» للسماح بإشعارات الطلبات الجديدة أثناء فتح لوحة الإدارة. التنبيهات لا تعمل إذا كان المتصفح أو الجهاز مغلقًا.

## واجهات API
- `GET /api/products` — قائمة المنتجات.
- `POST /api/coupon` — التحقق من كود الخصم.
- `POST /api/orders` — التحقق من الطلب وحفظه في SQLite مع احتساب الأسعار من الخادم.
- `GET /api/health` — فحص حالة الخادم.
- `GET /api/admin/orders` — قائمة الطلبات وملخص المبيعات (يتطلب تسجيل دخول الإدارة).
- `PATCH /api/admin/orders/<order_id>/status` — تحديث حالة الطلب (يتطلب تسجيل دخول الإدارة).

## قبل النشر الحقيقي
- استبدل الصور المؤقتة في `static/images/` بصور المنتجات الأصلية؛ ملف HTML الذي وصلنا لم يتضمن ملفات الصور.
- راجع رقم واتساب، طرق الدفع، الأسعار وسياسة التوصيل. واجهة الدفع الحالية تسجل اختيار طريقة الدفع فقط ولا تنفذ تحصيل أموال إلكترونياً.
- اضبط `SECRET_KEY` و`ADMIN_PASSWORD` و`NEXO_WHATSAPP` و`NEXO_COUPON_CODE` كمتغيرات بيئة في منصة الاستضافة. فعّل `COOKIE_SECURE=1` عند استخدام HTTPS.
- استخدم HTTPS، وفعّل نسخاً احتياطية لقاعدة البيانات، ولا تعتمد على SQLite إذا كانت بيئة الاستضافة تحذف الملفات أو تشغّل عدة نسخ متزامنة.
- لوحة الإدارة محمية بكلمة مرور من متغير البيئة `ADMIN_PASSWORD`. لا تنشر المتجر قبل ضبط كلمة مرور قوية و`SECRET_KEY`، ولا تشارك بيانات الدخول.
- لوحة الإدارة تحدث البيانات كل 10 ثوانٍ أثناء فتحها. إشعارات المتصفح تتطلب منح الإذن، وتعمل فقط عندما تكون اللوحة والمتصفح مفتوحين. لإشعارات تعمل والجهاز مغلق، تحتاج إلى خدمة إشعارات خارجية.

## ملاحظات المراجعة
- النسخة الأصلية كانت واجهة أمامية فقط: السلة والمفضلة والرسائل والطلبات كانت في `localStorage`، ولا يوجد خادم لحفظ الطلبات.
- روابط `manifest.json` و`sw.js` كانت تشير إلى ملفات غير مرفقة؛ أُضيفت ملفات PWA أساسية.
- لم تُرفق صور المنتجات، لذلك أضيفت صور بديلة مؤقتة تحمل تنبيهاً بأنها تحتاج صوراً حقيقية.
- لم يُضف مزود دفع إلكتروني؛ زر الطلب يفتح واتساب بعد حفظ الطلب على الخادم.
